# 毫厘账（HaoliZhang）

水墨丹青风格的 Windows 桌面记账应用。无边框窗口、行楷标题、朱砂点睛——把记账写成一本雅致的账房日记。

## ✨ 特性（V1.1）

- **三页一体**：记一笔 / 账本 / 统计，分类标签管理与导入导出内置其中，无冗余导航
- **水墨 UI**：宣纸留白、行楷书法标题、批注式导航、卡片角花、朱砂印章
- **无边框窗口**：自绘朱砂线式标题栏（铜钱图标 + 毫厘账），可拖动、双击最大化
- **通栏结余条**：主界面底部常驻——竖式「收入 / 支出 / 结余」（中文大写为主体，数字引号注释），日历支持自由选日与**范围选取**，中间每天一句行书诗句
- **全量自绘组件**：弹窗、右键菜单、日期/月份/下拉面板全部水墨化，无原生控件残留
- **统计**：日/月/年/自定义区间，分类占比、收支趋势（双轴）、预算执行
- **预算**：总额 + 分类预算，进度分级（正常/预警/超支），豁免不计入
- **豁免机制**：重大支出可标记豁免——不计入常规支出与预算，但计入真实结余
- **导入导出**：Excel 导入（事务回滚、自动建分类）、CSV / 汇总文本导出（可交 AI 分析）
- **筛选排序**：账本按类型/豁免筛选，按日期/金额/分类排序
- **复制保护**：除数字与输入框外，界面内容不可选中复制

## 🚀 启动

```bash
npm install
npm start
```

## 🧪 测试

```bash
npm test        # 20 项：记账 CRUD / 统计口径 / 预算 / 导入导出 / 分类标签
```

## 📦 打包

```bash
npm run dist    # 产物在 dist/：毫厘账 Setup x.y.z.exe（安装包）+ 毫厘账 x.y.z.exe（便携版）
```

## 📁 结构

```
electron/   主进程（窗口 / IPC / 数据库 / 导入导出）
renderer/   渲染端（界面：index.html / styles.css / ui.js / pages/ 三页面）
tests/      测试（20 项）
build/      应用图标
```

## 📐 统计口径

| 场景 | 豁免 |
|---|---|
| 当日/当月常规支出、预算进度、超支警告 | 不含豁免 |
| 当日/当月结余、区间结余 | 含豁免（真实结余） |
| 季度/年度总支出 | 含豁免 |
