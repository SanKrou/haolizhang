# 记账应用（Ledger App）设计文档

- **日期**：2026-07-31
- **状态**：已获用户逐段批准

## 1. 背景与目标

个人记账需求：记录日常收入与支出，按日/月/年统计与计算结余，设置月度预算并预警超支，支持导出数据供 AI 分析建议。

**成功标准**：
- 在 Windows 上作为桌面应用流畅运行（界面精美、动画顺畅）
- 记一笔操作 ≤ 3 次点击完成
- 统计视图切换即时响应（< 200ms）
- 可一键导出 CSV + 汇总文本，数据可直接交给 AI 分析

## 2. 技术方案

**Electron 桌面应用**（用户选定）：
- 主进程（Node）：全部数据操作——SQLite 读写、Excel 导入导出、文件对话框
- 渲染进程：纯 UI 展示与交互，通过 IPC 与主进程通信
- 存储：SQLite 单文件数据库 `ledger.db`
- 图表：ECharts（饼图、折线趋势图）
- 界面：HTML/CSS/JS 自定义设计系统（圆角卡片、渐变、深色模式可选）

## 3. 总体架构

```
┌─────────────────────────────────────────────┐
│               Electron 应用                 │
│                                             │
│  ┌───────────────┐      ┌────────────────┐  │
│  │  渲染进程      │      │  主进程         │  │
│  │  (前端 UI)     │◄────►│  (Node 逻辑)   │  │
│  │  HTML/CSS/JS  │ IPC  │  数据读写       │  │
│  │  ECharts 图表  │      │  Excel 导入导出 │  │
│  └───────────────┘      └───────┬────────┘  │
│                                  │          │
│                          ┌───────▼────────┐ │
│                          │  SQLite 数据库  │ │
│                          │  (本地文件)     │ │
│                          └────────────────┘ │
└─────────────────────────────────────────────┘
```

- 渲染进程不直接触碰文件系统，所有数据操作经由主进程，保证数据安全
- 主进程暴露的 IPC 接口：记账 CRUD、统计查询、预算管理、分类/标签管理、导入导出

## 4. 数据模型（SQLite）

```
categories   分类表    id, name(名称), type(income/expense), sort_order
tags         标签表    id, name
transactions 记录表    id, type(income/expense), amount(整数分),
                       date, category_id, note(备注),
                       exempt(0/1 是否豁免), exempt_note(豁免原因),
                       created_at
tx_tags      关联表    transaction_id, tag_id      -- 记录↔标签 多对多
budgets      预算表    id, category_id(NULL=总额预算), month(YYYY-MM), amount
```

- 金额用**整数分**存储，避免浮点误差；显示时除以 100
- `transactions.date` 建索引；日/月/年统计走 `GROUP BY strftime()` 聚合

### 统计口径规则（豁免支出）

| 场景 | 是否含豁免支出 |
|---|---|
| 当月支出统计 / 预算进度 / 超支警告 | ❌ 不含 |
| 当月结余（当月收入 − 全部支出） | ✅ 含（真实结余） |
| 季度、年度总支出 | ✅ 含 |
| 独立「重大支出」分区 | 仅展示豁免记录（月底可查看） |

## 5. 界面组件（6 个视图）

| 视图 | 功能 |
|---|---|
| **记一笔** | 默认打开页：支出/收入切换、金额、分类下拉、标签多选、日期、备注、**豁免开关 + 豁免原因**、保存 |
| **账本** | 按日期分组记录列表，分页加载，每条可编辑/删除 |
| **统计** | 日/月/年切换；结余卡片（总收入/总支出/结余）+ 分类饼图 + 收支趋势折线图；月视图含**「重大支出」独立分区** |
| **预算** | 设置月度预算（总额+分类）、进度条展示、超支标红警告（仅按常规支出计算） |
| **导入导出** | 导入 Excel（.xlsx）、导出 CSV + 汇总文本 |
| **管理** | 分类/标签增删改、查看数据文件位置 |

主界面：左侧导航栏切换视图，右侧内容区，顶部显示当月结余。

## 6. 数据流

### 记账
```
「记一笔」填写（金额/分类/标签/豁免）
 → 渲染进程本地校验（金额>0、分类必选、日期合法）
 → IPC → 主进程事务写入 SQLite
 → 返回成功 → 清空表单 + 刷新统计卡片/图表（平滑动画）
```

### 统计
```
切换日/月/年 → IPC → SQL 聚合（GROUP BY 日期/分类）
 → 按豁免规则分别计算常规支出、豁免支出、结余（含豁免）
 → 返回 → ECharts 饼图/趋势图 + 卡片数字滚动动画
```

### 导入（Excel）
```
选择 .xlsx → 主进程解析 → 分类/标签自动匹配，未匹配提示新建
 → 预览前 N 行 → 用户确认 → 事务批量写入，任一行失败整体回滚
```

### 导出（CSV + 汇总文本）
```
选择保存位置 → 查全部数据
 → CSV（含豁免标记列；UTF-8 with BOM，Excel 打开不乱码）
 → 汇总文本（月度收支、分类占比、预算执行、结余趋势、重大支出清单）
 → 弹窗提示保存位置
```

## 7. 错误处理

- 输入非法：表单内联红字提示，不弹窗打断
- 数据库损坏：启动时完整性检查，异常时提示并引导导出备份
- 导入格式错误：逐行标出问题行，可放弃或修正后重试，不半途而废
- IPC 异常：统一错误弹窗 + 日志文件

## 8. 性能与动效规范

- 列表**分页加载**（每页 100 条）；统计用 SQL 聚合而非前端循环
- 大列表用虚拟滚动
- 界面切换用 CSS transition/animation（GPU 加速）：卡片淡入、数字滚动动画
- ECharts 自带过渡动画（饼图展开、折线绘制过程）
- 数据变更以平滑过渡刷新，不做生硬整页刷新

## 9. 测试

- 数据层单元测试（Node 内置 `node:test`）：CRUD、统计聚合（**重点覆盖豁免规则**）、预算计算、导入解析
- 手动验收清单：6 个视图完整操作流程 + 异常输入场景

## 10. 非目标（YAGNI）

- 不做多用户 / 登录 / 云端同步
- 不做多币种
- 不做移动端
- 不做数据加密（个人本地使用）
